Windows CMD Deployment Guide (no && chaining needed)

1. Backend test:
double-click start-backend-windows.cmd
or CMD: cd backend (enter)
npm install (enter)
npm start (enter)

Test: browser http://localhost:5000/health

2. Git backend:
cd backend
git init
git add .
git commit -m "Deploy ready"
hub create sudan-quality-backend (if hub installed) or github.com new repo
git remote add origin https://github.com/YOUR/sudan-quality-backend.git
git push -u origin main

3. Vercel:
vercel.com dashboard > New > Import repo > Deploy

4. Frontend:
cd frontend
npm run build
firebase deploy

Done!
